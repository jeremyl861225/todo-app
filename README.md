# 待辦事項

重複排程與月曆合一的待辦事項 PWA，手機與電腦共用同一份資料。

**線上版本**：<https://jeremyl861225.github.io/todo-app/>

![screenshot](icon-192.png)

## 功能

**頁面一 — 重複排程**
- 依「每日 / 每週 / 每月 / 自訂」分組列出
- 每筆都有**起始日**（必填，預設當天）與**結束日**（選填，留空表示持續進行）
- 自訂＝每 N 天／每 N 週（週幾）／每 N 個月（幾號），從起始日起算
- 每月選幾號；當月沒有那天時自動落在該月最後一天
- 新增、編輯、刪除；點卡片看完整內容
- 每筆包含標題、時間、敘述、相關連結（自訂名稱＋網址，可多筆）、類別
- 已過結束日的排程在清單上會淡化並標「已結束」

**頁面二 — 月曆**
- 與頁面一即時同步，桌機在格子內顯示事項、手機顯示彩色圓點
- 勾選完成，**只影響被勾的那一天**
- 可新增「單一行程」，**支援跨多日活動**（例如 8/12–8/14 的研討會，每天都會出現並標示第幾天）
- 單一行程與重複排程在月曆上樣式不同：單一行程是圓角描邊色塊／菱形點，
  重複排程是灰底左側色條／圓點
- 僅單一行程能在此頁編輯／刪除；重複排程只能勾完成，內容要回頁面一修改

**其他**
- Email + 密碼註冊／登入，登入狀態會記住
- 類別可自訂（預設「工作」「私人」）
- 匯出備份 JSON

## 資料保存

1. 所有變更立即寫入 Supabase（雲端）
2. 同時在瀏覽器留一份快取，開啟時先顯示快取再與雲端對時 → 離線或連線失敗**不會變空白**
3. 離線時的操作進入待上傳佇列，右上角顯示「待上傳 N」，恢復連線自動補送
4. 選單可手動匯出 JSON 備份

## 技術

- 單一 `index.html`，無建置流程
- [Supabase](https://supabase.com) 提供 Email/密碼登入與 Postgres；Row Level Security 確保每個帳號只讀得到自己的資料
- `sw.js` 刻意**不建立任何快取**：這個 App 需要即時雲端資料，且同網域下還有其他 PWA，不做快取就不會互相影響

## 自行部署

見 [SETUP.md](SETUP.md)：建立 Supabase 專案 → 執行 [schema.sql](schema.sql) → 填入 `index.html` 最上方的 `CONFIG` → 放上 GitHub Pages。

不想設定也可以先加 `?demo=1` 試用，資料只存在本機瀏覽器。
